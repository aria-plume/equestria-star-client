# Godot 童话风第一层 HUD 接入记录

更新时间：2026-11-08。

## 接入范围

- 仅重排 `GameHud` 第一层信息与入口，不修改二级卡牌、任务、判定、奖励或骰子界面。
- 使用 `assets/art/ui/fairytale_hud/` 的 7 张 PNG 圆形按钮和 14 张 SVG 容器/装饰；文字、顺序、数值和玩家名仍由独立控件绑定权威数据。
- `GameScreen` 组合时隐藏 `GameMapScene` 自带的旧地图信息标签，独立运行地图场景时仍保留该诊断标签；地图加载、错误和重试流程不变。

## 布局与绑定

- 左上：回合顺序标题、竖线、箭头和动态其他玩家条目；条目继续按 `turnOrder` 排序并保留悬停详情。
- 顶部中央：童话横幅继续绑定当前回合、暂停和阶段提示。
- 右上：正式地图标识、公共任务板和公共货架入口。
- 右侧中部：魔杖入口展开打工、铁路、判定和结束回合；结束回合不再保留独立入口。
- 左下：当前玩家名占位头像、姓名缎带、金币、声望和有效六维。
- 右下：道具、个人任务、装备、伙伴；伙伴仍为禁用占位。

## 输入边界

- `HudRoot`、锚点、装饰和透明容器均为 `MouseFilter.Ignore`。
- 七个圆形入口、行为菜单、玩家条目和详情面板使用 `blocks_map_input`；菜单隐藏后不会保留可命中的透明区域。
- 按钮继续依赖 Godot 原生 `Pressed`，没有在按钮自身 `GuiInput` 阶段提前消费事件。

## 验证边界

- 自动化和模拟传输只验证客户端绑定、GUI 分发和请求入口，不代表真实对局联调。
- 真实对局的公共任务、货架、道具、个人任务、装备、打工、铁路、判定和结束回合仍由用户在现有对局中验收，不在本次开发中写入服务端状态。

## 2026-11-08 审查修正

- 回合横幅、结束回合和打工资格已拆分刷新；阶段受限或存在奖励队首时，不再因打工分支早退而残留旧回合信息或可点击的结束回合状态。
- 左侧大矩形布局父节点不再标记 `blocks_map_input`；其他玩家只在实际条目和当前内容高度的滚动区拦截，当前玩家只在头像与状态条实际可见范围拦截。
- 其他玩家条目按局内 `playerId` 复用，正常玩家视图轮询不再清空重建条目。鼠标持续悬停时详情保持显示并更新数值；玩家移除、鼠标移出或 HUD 清理时正常关闭。
